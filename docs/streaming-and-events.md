# Streaming & Events

SAGU is built around a single async generator architecture:
- `agent.stream()` yields fine-grained runtime events.
- `agent.run()` simply drains the stream and returns the final `RunResult`.

---

## Streaming Events with `agent.stream()`

```typescript
import { Agent, anthropic } from "sagu-sdk";

const agent = new Agent({
  name: "Assistant",
  instructions: "Help the user.",
  model: anthropic(),
  tools: [calculatorTool],
});

for await (const event of agent.stream("Calculate 45 * 12 and explain")) {
  switch (event.type) {
    case "text_delta":
      // Real-time token streaming from LLM
      process.stdout.write(event.text);
      break;

    case "tool_start":
      console.log(`\n[TOOL STARTED] ${event.name}`, event.arguments);
      break;

    case "tool_end":
      console.log(`\n[TOOL FINISHED] ${event.name}`, event.result);
      break;

    case "handoff":
      console.log(`\n[HANDOFF] Transferred to ${event.toAgent} (Reason: ${event.reason})`);
      break;

    case "guardrail_triggered":
      console.warn(`\n[GUARDRAIL ${event.action.toUpperCase()}] ${event.stage}: ${event.reason}`);
      break;

    case "run_completed":
      console.log(`\n[COMPLETED] Total Turns: ${event.turns}`);
      break;

    case "run_failed":
      console.error(`\n[FAILED] Error:`, event.error.message);
      break;
  }
}
```

---

## Event Catalog

| Event Type | Properties | Emitted When |
|---|---|---|
| `text_delta` | `{ text }` | Each token or chunk generated by the model |
| `tool_start` | `{ toolCallId, name, arguments }` | A tool execution begins |
| `tool_end` | `{ toolCallId, name, result, isError }` | A tool execution resolves or errors |
| `handoff` | `{ fromAgent, toAgent, reason }` | An agent transfers control to a specialist |
| `guardrail_triggered` | `{ stage, reason, action, toolName }` | An input, output, or tool guardrail triggers |
| `run_completed` | `{ output, messages, usage, agentName, turns, trace }` | Run successfully completes |
| `run_failed` | `{ error, messages, usage, agentName, turns, trace }` | Run fails (e.g. guardrail block, timeout) |
